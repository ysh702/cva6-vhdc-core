# VV35 布局布线后门级 SAIF 功耗与能量报告

## 1. 结论

本轮使用同一个 VV35 最终布局布线检查点、相同随机 K、相同 1632 次四分类驻留原型 HMATCH 工作量，分别运行严格串行与交织调度。两种场景均通过带最大路径与互连延迟的门级仿真，PMUL 坐标、全部 HMATCH 返回、ECC 状态与 VRF 保护行均正确。

门级 SAIF 在最终 DCP 上匹配 4139/7284 条设计网络，实际比例为 56.82%，Vivado 报告四舍五入为 57%。匹配率由原 RTL SAIF 的 13% 显著提高，Vivado 将两种场景的总体功耗估计置信度均评为 High。

交织调度使平均总功耗提高 21.277%，平均动态功耗提高 38.462%，但任务时间缩短 40.760%。Vivado confidence 为 High 的布局布线后活动驱动估计表明，总能量约下降 28.2%，动态能量约下降 18.0%。更高的瞬时硬件活动被更短的任务完成时间抵消，并形成估算的净能量收益。

## 3. 固定工作量与正确性

两种场景使用：

- 一个随机 K-233 PMUL；
- 同一已编码查询；
- 同一组四个驻留原型；
- 1632 次相同 HMATCH 请求；
- 期望分类为 class 0，期望分数为 505，期望返回为 `0x00000000000001f9`。

门级结果如下。

| 检查项 | 严格串行 | 交织调度 |
|---|---:|---:|
| XSim PASS 标志 | 1 | 1 |
| PMUL 最终状态 | PASS | PASS |
| PMUL X/Y 坐标 | PASS | PASS |
| HMATCH 完成数 | 1632 | 1632 |
| HMATCH 错误数 | 0 | 0 |
| 公开端口未知值 | 0 | 0 |
| VRF row 3/6/7 保护 | PASS | PASS |
| 活动周期 | 337853 | 200144 |
| SAIF 持续时间 | 1689265000 ps | 1000720000 ps |

337853 拍与 200144 拍是由 plusarg 回放的冻结周期合同。门级测试证明全部固定工作量均在对应窗口内完成，并不是让测试台重新搜索自然结束时刻。SAIF 持续时间与冻结周期乘以 5 ns 完全一致，没有额外记账尾拍。

## 4. 功耗与能量

| 指标 | 严格串行 | 交织调度 | 变化 |
|---|---:|---:|---:|
| 活动周期 | 337853 | 200144 | -40.760% |
| 活动时间 | 1.689265 ms | 1.000720 ms | -40.760% |
| 平均总功耗 | 0.235 W | 0.285 W | +21.277% |
| 平均动态功耗 | 0.130 W | 0.180 W | +38.462% |
| 静态功耗 | 0.105 W | 0.105 W | 0 |
| 估算总能量 | 0.396977 mJ | 0.285205 mJ | **约 -28.2%** |
| 估算动态能量 | 0.219604 mJ | 0.180130 mJ | **约 -18.0%** |
| 物理网络匹配 | 57%（4139/7284） | 57%（4139/7284） | 相同 |
| Vivado confidence | High | High | 相同 |

计算式为：

\[
T=\frac{C}{200\times 10^6},\qquad E=P\,T.
\]

周期收益为：

\[
\Delta C=337853-200144=137709,
\]

\[
R_C=\frac{137709}{337853}=40.760\%,\qquad
S=\frac{337853}{200144}=1.68805.
\]

总能量收益为：

\[
R_E=\frac{0.396977275-0.285205200}{0.396977275}=28.156\%\approx28.2\%.
\]

动态能量收益为：

\[
R_{E,\mathrm{dyn}}=
\frac{0.219604450-0.180129600}{0.219604450}=17.975\%\approx18.0\%.
\]

上述细分数值由 Vivado 以三位小数输出的功率计算，因此正文采用一位小数的能量变化，完整算术值仅用于结果复核。

## 5. 与原 RTL SAIF 结果的关系

原 RTL SAIF 只能匹配 952/7284 条物理网络，匹配率为 13%，Vivado confidence 为 Medium。其估算总能量下降 19.866%，动态能量下降 4.171%。

本轮直接仿真布局布线后 timesim 网表，物理网络匹配提高到 4139/7284，即 56.82%，Vivado 报告为 57%，其功耗估计 confidence 提升为 High。由此得到的正式估算为总能量约下降 28.2%，动态能量约下降 18.0%。论文及后续汇总应优先采用本轮门级结果，旧结果仅保留为方法演进记录，不应与本轮数值混用。

## 6. 物理活动解释

交织调度使同一时间内有更多既有功能单元处于活动状态，因此：

- Slice Logic 功耗由 0.030 W 增至 0.046 W；
- Signals 功耗由 0.058 W 增至 0.090 W；
- Clocks 功耗由 0.013 W 增至 0.015 W；
- Block RAM 功耗保持 0.028 W；
- 静态功耗保持 0.105 W。

平均功耗上升符合细粒度交织提高硬件时间利用率的物理预期。任务完成时间下降幅度大于平均功耗上升幅度，因此总能量与动态能量均下降。

## 7. 证据边界

本轮结果是当前没有开发板时更强的 FPGA 功耗证据，Vivado 将其功耗估计 confidence 评为 High，但仍有以下边界。

- 这是布局布线后活动驱动的功耗估计，不是开发板电源轨实测。
- 57% 的设计网络由门级 SAIF 直接标注，剩余网络由 Vivado 概率模型传播活动。
- 两次 XSim 各有两条 `$readmemh` 文件字数多于仅读取范围的警告。测试台只使用所需首项，全部结果检查通过，该警告不影响功能或活动窗口，但本轮不能表述为零 warning。
- `TIMINGCHECK` 被移除，门级功能仿真不替代最终 setup/hold STA。
- 当前顶层是独立 HDEC 核，不包含 CPU、CV-X-IF、封装引脚、板级电源转换损耗与外部存储。
- 门级公共接口测试证明相同工作量、结果与物理活动。1177 次内部配对接受、18832 次位矩阵/POPCOUNT 配对事件与零共享资源冲突仍由原 RTL 白盒回归证明。
- 这项测试是对既有统一表示、共享架构与交织调度的证据强化，不构成新的论文级创新。
